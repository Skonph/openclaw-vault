Phase 1 — Nightly Scan & Intelligence
Server cron at 21:05 Bangkok (Mon–Fri) · openclaw_scanner.py
1
Macro fetch — VIX, SPY, sector ETFs
Tradier API pulls live quotes for VIX, SPY, XLE, XLY, XLI, XLB, XLC, XLF.
Gate: VIX ≥ 20 OR SPY change ≤ −1.5% → market blocked, no new bull call entries today.
auto
2
Sector ETF EMA20 direction check
45-day price history → compute EMA(20) per sector ETF.
ETF above EMA20 → bull call spreads only for that sector's tickers.
ETF below EMA20 → bear put spreads only. Unknown → scan both.
auto
3
Spread scan across candidates.txt (13 tickers)
Tradier options chains per ticker × expiry in 25–40 DTE window.
Hard filters applied to every leg: IV Last ≤ 45% (L019) · OI ≥ 500 · Bid > $0 · Bid-ask ≤ $0.10 · Net debit $0.30–$0.60 · Spread width ≤ $3 · R:R calculated · KNOWN_HOLDS skipped (e.g. PR until Jun 17).
Best R:R per ticker+type kept after deduplication.
auto
4
Events calendar check — Tradier fundamentals/calendars
Checks earnings ± 14 days and ex-dividend dates within 14 days forward for each qualifying ticker.
BLOCKED — confirmed event in window → skip.
CLEAR — no events found → proceed.
UNCERTAIN — Tradier returned no data → proceed but flag ⚠️ for IBKR check before approval.
auto
5
Conviction scoring — Claude Haiku API
Calls Anthropic API (claude-haiku-4-5-20251001) with full spread context.
Scores 0–100 across: liquidity (OI depth, bid-ask tightness) · volatility setup (IV rank, IV last) · structure (R:R, DTE sweet spot 28–35) · market alignment (ETF direction, VIX level).
Score < 75 → rejected. Score ≥ 75 → proceeds to approval queue.
auto
6
Write pending_orders.json + snapshot JSON
approval_manager.py writes qualifying trade to OpenClaw/pending_orders.json in vault.
Trade ID assigned (e.g. A1B2C3D4) · expires 6 hours after creation.
Full scan snapshot written to ~/trading-bot/logs/snapshots/.
auto

Phase 4 — Trade Execution
Triggered immediately on Approve · via dashboard (browser) or nova_executor.py (Nova)
10
Build OCC symbols + submit Alpaca mleg order
OCC format: NCLH260620C00017000 (symbol + YYMMDD + C/P + strike×1000 padded 8 digits).
2-leg limit order: buy long leg + sell short leg · limit = mid × 1.05 (5% slippage buffer) · time_in_force: day.
Dashboard path: browser JS calls POST /v2/orders directly.
Nova path: nova_executor.py calls same endpoint via Python requests.
auto
11
Execution logged + order marked executed

Next nightly vault push syncs log to GitHub.

💰 Profit target — unrealised profit ≥ 50% of debit at DTE ≤ 21 → EVALUATE EARLY CLOSE.
auto

Exception — IBKR Manual Check
Only required when events_status = UNCERTAIN
!
When does this happen?
Tradier fundamentals/calendars returned no data for a ticker (thin coverage on some small-caps like PUMP, SBSW).
Trade still goes to approval queue but dashboard shows ⚠️ UNCERTAIN badge and Nova warns in chat.
exception
!
Action: check IBKR Events Calendar manually
In IBKR TWS/Portal → Events Calendar → enter ticker → check entry date through expiry date window.
No earnings/dividends in window → Approve via dashboard or Nova.
Events found → Reject with reason noted (dashboard or Nova).
human
